# Sustainable Stock Market Analysis & Prediction Using Machine Learning

## Project Overview
This project analyses historical stock market data and uses machine learning techniques to study stock trends, predict market direction and examine investment risk.

## Technologies Used
- Python
- Streamlit
- Pandas and NumPy
- Scikit-learn
- yfinance
- Plotly

## Machine Learning Algorithms
- Logistic Regression
- Random Forest Classifier
- Random Forest Regressor
- K-Means Clustering

## Features
- Historical stock market data analysis
- Technical indicators such as RSI, SMA, EMA and MACD
- Machine learning-based prediction
- Risk and volatility analysis
- Interactive Streamlit dashboard
- SDG and sector view

## Data Source
Historical stock data is fetched using Yahoo Finance through the yfinance Python library.

## Installation and Execution

1. Clone this repository:
   `git clone https://github.com/mayankshrm1332/Sustainable-Stock-Market-Analysis-ML-1-.git`

2. Open the project folder.

3. Install dependencies:
   `pip install -r requirements.txt`

4. Run the application:
   `streamlit run app.py`

## Limitations
Predictions are experimental and based on historical data. They are not guaranteed to predict future prices or provide financial advice. The project does not calculate official ESG scores.
